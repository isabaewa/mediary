## Термины

Ветка — отдельная линия работы с исходниками. Коммит — сохранённый этап изменений. Worktree — отдельная рабочая папка того же репозитория. Pull request — предложение слить изменения одной ветки в другую с просмотром разницы. Merge — объединение истории веток. Конфликт возникает, когда Git не может автоматически согласовать изменения одного участка.

Учебный PR объединён с учебной интеграционной веткой. Текущий рабочий каталог пользователя остаётся на main со своими локальными изменениями.
