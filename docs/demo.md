# Демонстрация Mediary

Учебный сценарий рассчитан на 7 минут.

1. Зарегистрировать отдельный демонстрационный аккаунт и войти.
2. Добавить регулярный препарат с курсом на сегодняшний день.
3. Отметить приём на главной и показать обновление прогресса.
4. Создать запись в дневнике, показать ошибку оценки боли 11.
5. Исправить оценку на 4 и сохранить запись.
6. Найти запись через поиск и показать Fetch во вкладке Network.
7. Открыть карточку, изменить заметку, затем удалить запись с подтверждением.
8. Показать тесты, структуру проекта и историю Git.

Для демонстрации используются искусственные данные.
